## 6. LOB区分 複数選択UI

### 6.1 動作仕様

LOB区分は複数選択可能な特殊フィールドであり、単純な下拉框ではなく**カスタム多選択コンポーネント**で実装する。

**コンポーネント構造**:
```
┌──────────────────────────────┐
│ [RSL ✕] [RSL(佐川) ✕] [▾]   │  ← 選択済みタグ表示エリア
├──────────────────────────────┤
│ クリックでドロップダウン展開  │
└──────────────────────────────┘
     ↓ 展開時
┌──────────────────────────────┐
│ ☑ RSL                        │
│ ☐ RSL(1stParty)              │
│ ☑ RSL(佐川)                  │
│ ☐ サテライトRSL              │
│ ☐ BOOKS                      │
└──────────────────────────────┘
```

- **選択肢**: RSL, RSL(1stParty), RSL(佐川), サテライトRSL, BOOKS
- **タグ**: 選択したLOBは青バッジで表示、各タグに`✕`ボタン付き
- **ドロップダウン**: クリックで開閉、チェックボックス式で選択/解除
- **背景オーバーレイ**: ドロップダウン以外のクリックで閉じる
- **バリデーション**: 新規登録時に最低1つのLOB選択が必要 (alert表示)
- **一覧表示**: LOB区分カラムでは選択済みLOBを青バッジ横並びで表示

### 6.2 注意点
- 編集中は`lobCategory`をスプレッドコピーして状態管理 (`[...store.lobCategory]`)
- グリッド内で他のフィールドより高さが大きくなる可能性あり
- 新規登録時のバリデーションでLOB未選択をチェック

## 10. 注意事項・制約

1. **店舗コードの一意性**: storeCdはシステム内でユニーク。新規登録時に重複チェックを行い、重複時はalert表示。
2. **店舗コード編集不可**: 編集モーダルではstoreCdフィールドはdisabled。新規登録時のみ入力可能。
3. **LOB複数選択**: LOB区分は複数選択可能な特殊UI。スプレッド構文で状態コピー必須。
4. **住所プレースホルダ**: 住所1〜3のinputにはそれぞれの提示文言をplaceholderとして表示。データ保存時は値のみ保存。
5. **3カラムグリッド**: 編集/登録モーダルは md 以上で3カラム、モバイルで1カラムにレスポンシブ対応。
6. **サービス利用状態の色分け**: 一覧表示でStatusBadgeを使用。稼働=緑、停止/休止=黄。
7. **モーダルサイズ**: 2xl (max-w-6xl) を使用。コンテンツが多いため70vhのスクロール領域を確保。
8. **未実装機能**: CSV出力はプレースホルダー段階。
9. **長期保管月単価**: 管理情報セクションに追加。必須ではないがデフォルト値`23`を持つ。
10. **得意先コード**: 管理情報セクションに配置。必須ではないが(*)表示あり。
