# 配送日曆ページ 設計書

## 基本情報
- **ルート**: `/delivery/calendar`
- **コンポーネント**: `src/app/delivery/calendar/page.tsx`
- **タイプ**: Client Component
- **認証**: なし（セッションチェックなし）
- **データ**: 自動生成スケジュール（年間24件 = 月2件）

---

## ページ構成
- レイアウト: `w-full px-8 py-8`
- `PageHeader` title: 「配送日曆」、description: 「入金・決済・出金のスケジュール管理。」
- アクション: 年セレクトボックス（2024/2025/2026）

---

## 機能概要
1. 年間スケジュールカレンダー表示（月別カードグリッド）
2. 月別にスケジュールエントリをカード表示
3. エントリの編集（モーダル）
4. 次回入金日表示
5. 総登録件数表示

---

## データ型: `ScheduleEntry`

| フィールド | 型 | 説明 |
|-----------|------|------|
| `id` | `string` | 一意ID（`{year}-{month}-{depositDay}`） |
| `year` | `number` | 年 |
| `month` | `number` | 月（0-based） |
| `depositDate` | `number` | 入金日（日） |
| `settlementDate` | `number` | 決済日（日） |
| `withdrawalDate` | `number` | 出金日（日） |
| `remark` | `string` | 備考 |

---

## スケジュール生成ロジック
- デフォルト入金日: 12日、27日（月2回）
- 決済日 = 入金日 + 2日
- 出金日 = 入金日 + 5日
- 月跨ぎ対応: 日数超過時は月初に補正

---

## 集計カード（3カラム）
| カード | 値 |
|--------|------|
| 総登録件数 | `totalEntries` |
| 年間予定月数 | 12ヶ月 |
| 次回入金日 | 次回入金日（日付フォーマット + 備考） |

---

## 月別カードグリッド（3カラム）
- 各月カード:
  - ヘッダー: `bg-accent text-white` の月名
  - エントリ一覧: 各エントリはクリック可能なカード
  - エントリ表示:
    - 入金日
    - 決済日 / 出金日
    - 備考（存在する場合のみ）

---

## 編集モーダル
- タイトル: 「日程編集」
- サイズ: `"sm"`
- 表示: 「{year}年 {month} — {depositDay}日 入金」
- 編集フィールド:
  - 入金日（number, min=1, max=31）
  - 決済日（number, min=1, max=31）
  - 出金日（number, min=1, max=31）
  - 備考（textarea, 2行）

---

## 状態管理
| 変数 | 用途 |
|------|------|
| `selectedYear` | 選択年 |
| `schedules` | 年単位のスケジュールマップ |
| `editModalOpen` | 編集モーダル表示状態 |
| `editingEntry` | 編集中のエントリ |

---

## 依存コンポーネント
- `PageHeader`
- `Modal`

---

## 注意事項
- このページは他のページと異なりセッションチェックを行わない（`useSession`未使用）
- データは同日内に編集可能で、`schedules`状態に保存される
- 年をまたぐデータは別の年として保存され、年切替時に表示切替
